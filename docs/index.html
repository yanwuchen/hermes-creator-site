Hermes Creator

Hermes Creator 是 yanwuchen 维护的个人创作资料整理工具，帮助整理聊天中的灵感、小红书文案、抖音脚本和相关媒体素材。此应用供维护者本人使用，目前不提供公众注册服务。

资料整理流程

用户通过聊天与 Hermes 讨论创作思路。值得保存的结论由用户确认后收录，文字和素材索引存入私有 GitHub 创作仓库，图片、音频和视频存入用户的 Google Drive 素材目录。

Google Drive 的用途

应用通过 Google Drive API 查看素材目录和文件信息、创建选题目录，并根据用户指令上传媒体。用户在 Google 授权页面亲自授权后，应用才可访问其云盘。

当前请求完整 Drive 权限，该权限在技术上可访问、修改和删除账号内的全部 Drive 文件，并非只限于素材目录。应用操作约定以创作素材目录和用户明确指定的文件为范围，不自动公开素材或发布到社交平台。

数据与联系

了解数据访问、AI 处理、保存和撤销授权方式，请阅读隐私政策。
